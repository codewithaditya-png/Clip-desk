# Clip Desk

A lightweight production board for YouTube and AI-video ideas. Track each clip from its first hook to publication.

## Try it

Open `index.html` in a browser. The app runs without an account or build step.

1. Select **New idea** and enter a title, format, and optional hook or notes.
2. Use the dropdown on a card to move it between **Ideas**, **In production**, and **Published**.
3. Search by title, format, or notes. Use **Edit** to update or delete a card.

The board starts empty. It saves to this browser using local storage when available. Browsers handle storage for local files differently, so the GitHub Pages version is the easiest way to keep using the same board. Cards do not sync across devices.

## Built with

HTML, CSS, and JavaScript. The source lives in a single file with no external dependencies.

## Publish with GitHub Pages

Upload both files to the root of a public repository named `clip-desk`. In **Settings → Pages**, choose **Deploy from a branch**, then select **main** and **/(root)**. Click **Save**. GitHub shows the site link on the Pages settings screen once the deployment finishes.
